# Product model

The rules the code must follow. Split into files as the product grows:

| File | Content |
|---|---|
| `DOMAIN.md` | concepts, business rules, statuses and lifecycles, permissions |
| `EXPERIENCE.md` | screens, their roles and main flows |
| `SCENARIOS.md` | scenarios with expected results; acceptance checklist |

When code and these documents disagree, point it out and fix whichever
is wrong.
